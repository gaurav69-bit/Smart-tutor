# ST-69 Registration Test Plan

Status: Draft — API contract awaiting team approval.

- REG-01: Valid student registration creates an unverified account.
- REG-02: Valid tutor registration requires admin approval.
- REG-03: Duplicate email registration is rejected.
- REG-04: Missing or invalid required fields are rejected.
- REG-05: Password is securely hashed, never stored as plaintext.
- REG-06: Public registration cannot create an admin account.
- REG-07: Missing required consent is rejected.
- REG-08: Responses never expose passwords, hashes or tokens.

Exact endpoints, response codes and fields require team agreement.
